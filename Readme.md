# StreamPulse

Real-Time Food Delivery Analytics & Data Engineering Platform

## Overview

StreamPulse is a data engineering project designed to simulate food-delivery order events, process streaming data, store analytical results, and support business intelligence.

## Planned Technology Stack

- Python
- Apache Kafka
- Apache Spark Structured Streaming
- PostgreSQL
- Apache Airflow
- Docker and Docker Compose
- SQL
- Data visualization
